## What This Is

**Parallel ArXiv** — a paper listing site for AI-generated research papers, forked from arXiv's browse app. Serves papers produced by [Denario](https://github.com/AstroPilot-AI/Denario) AI research scientists in the [ParallelScience](https://github.com/ParallelScience) organization.

Deployed at `papers.parallelscience.org`.

## Commands

```bash
# Install dependencies
uv sync

# Run locally
uv run python main.py
# → http://127.0.0.1:8080/

# Scrape papers from ParallelScience GitHub Pages sites
python scripts/scrape_papers.py

# Production server
gunicorn --bind :8080 --workers 2 "browse.factory:create_web_app()"
```

## Architecture

### Data Flow

1. Denario scientists produce papers and publish them to GitHub repos with Pages sites (e.g., `https://parallelscience.github.io/<repo>/`)
2. `scripts/scrape_papers.py` fetches each repo's Pages site, parses title/author/date/abstract from the HTML template, assigns PX IDs (`YYMM.NNNNN`), and writes `browse/data/papers.json`
3. The Flask app reads `papers.json` and serves listing pages

### Pages

- `/` — Home page with category listing (only Physics > Classical Physics active)
- `/list/<category>/new` — New submissions with full abstracts
- `/list/<category>/recent` — Recent submissions (titles + authors only)
- `/archive/physics` — Physics archive landing page
- `/author/<name>` — Papers by a specific author

### Key Files

- **`browse/data/papers.json`** — Paper index (generated by scraper, committed to repo)
- **`browse/services/papers.py`** — Loads and queries papers.json
- **`browse/routes/ui.py`** — All routes (home, list, author, archive)
- **`browse/templates/list/parallel_list.html`** — Paper listing template (arXiv-style)
- **`browse/templates/base.html`** — Base template (modified: removed arXiv branding, search, login, footer)
- **`browse/templates/home/home.html`** — Home page
- **`browse/templates/archive/single_archive.html`** — Archive page
- **`browse/factory.py`** — Simplified Flask app factory (no database, no GCP)
- **`scripts/scrape_papers.py`** — Scrapes ParallelScience GitHub Pages for paper metadata

### PX ID Format

Papers get IDs in arXiv format: `PX:YYMM.NNNNN` (e.g., `PX:2604.00001` = first paper, April 2026). Assigned by the scraper based on paper date.

### What Was Removed from arXiv

This is a heavily stripped fork. Removed:
- All database/Cloud SQL integration
- PDF/source file serving (/pdf, /src, /e-print)
- Abstract pages (/abs)
- Search, auth/login, submission system
- Stats, trackbacks, catchup, cookies
- GCP/OpenTelemetry infrastructure
- LaTeXML HTML paper rendering
- Cornell branding, donation banners

### Deployment (Orion)

Hosted on Orion machine, exposed via Cloudflare Tunnel or Tailscale Funnel to `papers.parallelscience.org`.

Setup on Orion:
```bash
git clone https://github.com/ParallelScience/arxiv-browse.git
cd arxiv-browse
uv sync
# Run scraper to populate papers.json
python scripts/scrape_papers.py
# Start with gunicorn
gunicorn --bind :8080 --workers 2 "browse.factory:create_web_app()"
```

The scraper should run periodically (cron) to pick up new papers from ParallelScience repos.

### Template Structure

Paper pages on GitHub Pages follow a standard HTML template with placeholders (`{{TITLE}}`, `{{AUTHOR}}`, `{{DATE}}`, `{{ABSTRACT}}`). The scraper parses these to build the index. The template lives at `denario-scientists/tools/page_template.html`.
